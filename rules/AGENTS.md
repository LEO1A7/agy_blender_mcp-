# AGENTS.md —— AGY Autonomous MCP 3D Modeling Plugin 核心规则

> 本插件提炼自高完成度三视图自主建模实践。模型应根据目标复杂度自主判定，自我组织多次分步骤、分组件递进建模，充分利用 MCP 交互式建模与即时反馈能力，逐步分段推进直至完成整体装配。
> 
> **官方参考底座与按需调取**：Blender 官方 MCP 完整脚本库及参考配方均收录于 `examples/`。官方 MCP 具备丰富的工具与 API，模型应自主根据建模、调整与修复需求，查阅并选用最契合的语句与方法，无需将全部算子塞入上下文。

---

## 1. 建模指导原则

- **自主分步组织**：面对复杂形体，模型应自主将目标拆解为若干独立组件或子系统（例如宏观体块 ➔ 重复阵列 ➔ 上部结构 ➔ 细部附件），分次调用 MCP `execute_blender_code` 逐步构建。分段建模可显著降低单次推演难度，并便于在中间阶段及时发现与修正偏差。
- **自主寻找合适语句**：官方 MCP 库包含丰富的场景检查、网格操作与视口渲染工具，模型自由使用原生 Python/BMesh 或官方 API 组织几何构造；如需复杂几何算子或质检参考，可在 `examples/` 按需提取。
- **手性与空间一致性**：严格统一右手系，避免左右镜像反转；子部件挂载时注意保持世界坐标一致。

---

## 2. 四阶段闭环工作流

### Stage 1：像素标尺网格标定（Pixel-Grid Calibration，按需挂载）
- **触发条件**：仅当输入包含**平面图、正交三视图、立面图或剖面图**等带正交投影/尺寸基准的图纸时启用；若输入仅为**透视图（照片/透视效果图）或无尺寸标注的轴测图**，**自动跳过本阶段标尺网格与线性像素换算约束**，直接依据视觉结构比例关系进入后续阶段。
1. 运行 `bin/blueprint_grid_calib.py` 在输入平面图/三视图上生成 `50px / 100px` 双色标尺网格 `blueprint_grid.png`。
2. 提取主尺寸标注换算唯一比例尺 $s = \frac{L_{\text{real}}}{\Delta u_{\text{px}}}\; (\text{m/px})$，并确定三向基准原点，通过线性映射函数快速换算坐标：
   - 纵向：`px_to_y(u) = (u - u0_mid) * s`（$-Y$ 前向，$+Y$ 后向）
   - 高程：`px_to_z(v) = (v0_ground - v) * s`（$+Z$ 向上，地面 $Z=0$）
   - 横向：`top_py_to_x(v) = (v0_top - v) * s`（$-X$ 右舷，$+X$ 左舷）

### Stage 2：右手系投影手性对齐（Handedness Alignment）
- 统一右手系：前向 $-Y$、上向 $+Z \Rightarrow$ 右舷（Starboard）为 $-X$、左舷（Port）为 $+X$。
  - **顶视图**：图像上半部为右舷（$-X$），下半部为左舷（$+X$）。
  - **正视图**：迎面视角下图像左半部为右舷（$-X$），右半部为左舷（$+X$）。
  - **侧视图**：车头朝左（$-Y$），相机位于 $+X$ 看向 $-X$。
- 对称与非对称部件建模前，交叉核对顶视与正视手性，确保左右朝向准确。

### Stage 3：自主分段 BMesh 几何建模（Autonomous Modeling）
- 模型自主决定拆解粒度与组件顺序，直接通过 MCP 调用原生 `bmesh` / `bpy` 语句逐次构建网格。
- 复杂曲面与多边形壳体封顶时，注意优先采用四边面（Planar Quads）连接，避免非共面 N-gon 产生阴影折痕伪影。
- 建模过程保持轻量，按需推进，不强制预加载冗余算子。

### Stage 4：视口视觉核验与自主调优（Visual Verification & Refinement）
1. 配置技术视口渲染（推荐 Workbench Cavity + Outline，可选开启多模块高对比度区分染色如 `color_type = 'OBJECT'` 或查阅配方，便于截图直观暴露构件穿插与错位）输出正交三视图与等轴测视图；支持通过 `bin/compose_triview_sheet.py` 生成多视图总览图或 1:1 三列边缘轮廓核验图。
2. 使用 `read_file` 审视效果，与原始三视图对账。
3. **自主增删改查与修复**：审视发现比例、位置或结构偏差后，模型自主根据需要从 MCP 库选择合适的语句（如查询对象包围盒、执行坐标微调、重构网格或增补部件），闭环调整直至整体几何准确。
